# entigo-infralib-example-release

Released snapshots of [entigo-infralib-example-source](https://github.com/entigolabs/entigo-infralib-example-source).

**This repository is generated.** It holds published releases only: no tests, no development history. Please do not open pull requests here. Module development happens in [entigo-infralib-example-source](https://github.com/entigolabs/entigo-infralib-example-source); the release workflow of [entigo-infralib-test](https://github.com/entigolabs/entigo-infralib-test) writes here.

It exists so that the whole test-and-release process of the framework can be exercised on a small repository before [entigo-infralib](https://github.com/entigolabs/entigo-infralib) adopts it, and it mirrors the relationship between entigo-infralib and [entigo-infralib-release](https://github.com/entigolabs/entigo-infralib-release).
